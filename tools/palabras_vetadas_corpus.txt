# Un patrón por línea. Cada patrón es una expresión regular de Python que debe
# coincidir con una palabra COMPLETA: el script los une con «|» y los rodea con
# \b(...)\b, sin distinguir mayúsculas. Un par se descarta si cualquiera de sus
# dos lados contiene una coincidencia. Las líneas vacías y lo que sigue a «#»
# se ignoran.
#
# Por qué patrones y no palabras sueltas: el español conjuga, y «coger» tiene
# una docena de formas. Por qué sin quitar acentos: así viene el corpus.
#
# Agregar un patrón cambia la muestra completa (se baraja después de filtrar):
# hay que regenerar los dos .jsonl y volver a leerlos.
